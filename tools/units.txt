# How each unit of the recompiled game code (generated/burnout3/unit_XXXX.cpp) is compiled for the page.
# tools/build-web.sh reads it (UNITS=none builds every unit the same way). A unit is 16 KiB of the game's
# code. The lists come from profiles: the page's emulation thread in a race (Chrome, frames 12650 to 13400)
# and native runs of the boot, the profile dialogs, the main menu and World Tour's event map.
#   hot   compiled at -O3 with the guest loads and stores inlined (PS2_INLINE_MEMORY): the units the race
#         spends its time in, 30 by self time plus helper time in the race, and the hottest of the menus
#   warm  compiled at -O3: the rest of the race's 100 busiest units, and every unit with 1% or more of the
#         game code's samples in a native run
#   (every unit not listed is compiled for size, -Oz: code those profiles ran little or not at all; in the
#   race it is 0.35% of the emulation thread)
